Quick Reference
--------------

🚀 START APP:
   python3 -m http.server 8000
   OR
   npx http-server -p 8000

🧪 TEST PWA:
   Open: http://localhost:8000/pwa-test.html

📱 INSTALL ON ANDROID:
   1. Open in Chrome
   2. Tap "Install"
   3. Launch from home screen

🎨 CUSTOMIZE:
   - Branding: manifest.json, index.html
   - Content: cms.js
   - Icons: icons/generate-icons.html
   - Colors: manifest.json, index.html

🌐 DEPLOY:
   See DEPLOYMENT.md for detailed instructions
