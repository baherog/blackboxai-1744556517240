CUSTOMIZATION QUICK REFERENCE
=============================

To Change Colors:
  Edit: assets/css/style.css (lines 8-18)
  Variables: --primary-color, --secondary-color, etc.

To Update Contact Info:
  Edit: config.php (lines 8-10)
  Update: SITE_EMAIL, SITE_PHONE, SITE_ADDRESS

To Modify Content:
  English: lang/en.php
  Arabic: lang/ar.php

To Add Logo:
  1. Save logo as assets/images/logo.png
  2. Edit: includes/navigation.php (line 3-5)

To Enable Email:
  Edit: contact.php (uncomment lines 31-35)

To Add New Page:
  1. Copy structure from any existing page
  2. Update navigation in includes/navigation.php
  3. Add translations in lang files
