# Icon Generation Instructions

## Option 1: Use the HTML Generator (Recommended)

1. Open `generate-icons.html` in a web browser
2. Icons will be automatically generated
3. Click the "Download" button under each icon
4. Save each icon with the displayed filename (e.g., `icon-192x192.png`)

## Option 2: Use the SVG File

The `icon.svg` file contains a scalable vector version of the app icon. You can:
- Use it directly (SVG is supported by modern browsers)
- Convert it to PNG using online tools like:
  - https://svgtopng.com/
  - https://convertio.co/svg-png/
- Use image editing software like GIMP, Inkscape, or Photoshop

## Option 3: Create Custom Icons

You can create your own icons using any design tool. Just ensure they:
- Are square (same width and height)
- Match the required sizes: 72x72, 96x96, 128x128, 144x144, 152x152, 192x192, 384x384, 512x512
- Are saved as PNG files
- Follow the naming convention: `icon-{size}x{size}.png`

## Placeholder Icons

If you don't have icons ready, the app will still work. Android will use a default icon until you replace these files with actual icons.
